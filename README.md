# eSperClient 1267 Research Notes

This repository contains the Markdown source for the GitHub Pages blog at
`0x00B4/skills-github-pages`.

The posts document an evidence-based reconstruction of the S4 League v1267
client: encrypted resource handling, the `.scn`, `.seq`, and `.oct` formats,
map loading, tick and effect timing, actor state transitions, and the limits of
a browser/WASM implementation.

The public author name used by the site is `0x00b4`. No personal profile,
credentials, archive keys, or private resource material is included.
